  1. 기출 재구성 2회독 → 모의 오답으로 대체 (적용함)
  2. 시냅스 4회독 → 5회독과 합치기

강의 스프린트 (v7.2 · 11/10 개정)

  1. 11/9 생리 24~32강 완강 (3강×3블록) + 저녁 OUTPUT 9주차 나머지
  2. v7.2: 워크북 2h 복구 — OUTPUT은 워크북 자리에 넣지 않음. 10주차·FINAL은 정해진 시간 없이 틈틈이 자율
  3. 우선순위: 생물 이론 인강 > 워크북 = 필수암기 > OUTPUT (밀리면 OUTPUT부터 미룸)
  4. 11/9에 못 들은 생물 2강 → 11/14 따라잡기 · 11/19 버퍼 · 생리 빈칸은 11/15 점검 때 자리 정하기
  5. 11/8~11/18 생물 통합이론 하루 2강 (8회분 · 10h) + 그날 단원 워크북 2h + 필수암기 2h
  6. 일요일 저녁 휴식 유지 → 11/8은 1강만 · 11/14(토)는 토익 준비 · 11/15 토익 뒤 2강
  7. 11/19 버퍼 — 남은 회분 + 모의① 원준 생리
  8. 원론 · 원문카드 · TB·N제 순서는 미정 → 11/15 주간 점검 때 정하기

기출 대체안 (v6.3 · 11/3)

  1. 기출 재구성본을 먼저 → 12/6(일) 낮 샘플 30분으로 판단
  2. 별로면 김영편입 권지연 기출풀이 강의+교재 (최근 3개년 · 한의사 응시 복기 · 15강 841분)로 교체 → 12/14 시작
  3. 교체하면 12/14~12/27 한의학 4h = 원문카드 2회독 2.5h + 기출 1.5h · 강의 2배속(약 7h), 막힌 곳만 정속
  4. 먼저 답 가리고 풀기 → 강의는 막힌 문제 위주 (대리만족 금지) · 오답은 원문카드 위치에 표시
  5. 밀린 강의는 일요일 낮(12/20 · 12/27)에 · 끝 12/27은 지킨다

회독 규칙

  1. 1회독 = 인풋 (답지 보며 역방향)
  2. 2회독 = 첫 아웃풋 (가리고 풀기, 오답 표시 · 찍어서 맞힌 것도 오답)
  3. 3회독부터 = 오답만 · 또 틀리면 오답 표시 하나 더
  4. 오답 표시 2개 이상 = 개념 리스트 후보 → 최종 200~300

진도 체크

칸을 누르면 완료 표시. 노란 테두리 = 이번 주에 나갈 범위 (모든 과목) · 빨간 점선 = 지난주까지 범위인데 아직 체크 안 된 칸 (일요일 낮에 따라잡기).
